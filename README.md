# data-analysis-projects

## Описание 
Предсказание вероятности того, что заемщик будет испытывать финансовые трудности в ближайшие 2 года для помощи банку определить, одобрять ли кредит. 

## Что сделано: 
- Загрузили датасет
- Предобработка данных
- Построены графики
- Выделены рекомендации банку по действиям для сокращения просрочек
- Выводы из анализа
- Поиск лучшей модели машинного обучения (из 7)
- Усреднение двух лучших моделей
- Общий вывод
